# VAcleaner v4.0.40 — Clear Package Names

Дата: 12.08.2026

## Що змінено

- Назви комплектів у бронюванні та на сторінці «Комплекти» приведено до однієї зрозумілої системи.
- Замість технічних або неповних назв картки одразу пояснюють сценарій: текстиль, вікна, кухня, ванна чи весь дім.
- Під назвами в бронюванні показано точний склад техніки та основні зони прибирання.
- Оновлено назви в адмінному виборі комплекту та серверному каталозі Supabase.
- Старі назви збережено як aliases, тому попередні посилання й бронювання продовжують розпізнаватися.

## Єдина система назв

- Глибоке очищення текстилю
- Текстиль + вікна
- Текстиль + кухня та ванна
- Генеральне прибирання
- Вікна та гладкі поверхні
- Весь дім · HOME RESET
