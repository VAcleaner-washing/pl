# VAcleaner v3.0.2 — settlement consistency hotfix

Базова збірка: **v3.0.1 P3 Architecture + correct settlement**.

## Виправлено

- прибрано залишкові рядки «Оплата при видачі» та «Уже отримано за оренду», які показували 0 грн через неіснуючі значення `f.issue` / `f.paid`;
- видача та повернення тепер скрізь використовують одну модель: **передоплата + фактичний залог − оренда − доставка − додаткові позиції − платна хімія**;
- у підсумках окремо показано передоплату, фактичний залог, отримано разом, витрати та фінальний результат;
- прибрано суперечливий текст «залог повертається окремо»;
- публічна форма більше не створює дубльований рядок залогу двома скриптами;
- збережено P3-архітектуру, єдиний конфіг, паспортні дані, аудит та ізольовану PWA.

## Перевірено

- `npm run stamp`;
- `npm run check`;
- `npm run build`;
- синтаксис основних JS-файлів;
- відсутність старих фінансових формулювань та звернень до `f.issue` / `f.paid`.
