# VAcleaner v3.0.12 — CONTROL VISUAL CONSISTENCY

Дата: 2026-08-06
База: v3.0.11 — PRODUCTION INVENTORY + CI HARDENING

## Завдання релізу

Виправити зсув правого блоку публічного бронювання під час відкриття календаря та привести всі dropdown/checkbox-компоненти адмінки до єдиного преміального вигляду.

## 1. Публічний календар

### Причина

При відкритті календаря для `documentElement` встановлювався `overflow: hidden`. На Windows зникав класичний вертикальний scrollbar, ширина viewport змінювалася, тому sticky-блок «Ваш вибір» зміщувався.

### Виправлення

- додано стабільний scrollbar gutter;
- scroll lock тепер вимірює фактично звільнену ширину після приховування scrollbar;
- компенсаційний `padding-right` додається лише тоді, коли gutter справді зник;
- попередні inline-значення `overflow` і `padding-right` відновлюються при закритті;
- повторне відкриття календаря не накопичує компенсацію.

## 2. Dropdown-и адмінки

Перевірено всі 6 звичайних `select`:

1. сортування клієнтів;
2. тип документа при опрацюванні заявки;
3. джерело бронювання;
4. техніка або комплект;
5. тип документа у новому/редагованому бронюванні;
6. спосіб видачі — самовивіз або доставка.

Для всіх застосовано:

- `appearance: none`;
- власну золоту стрілку;
- `color-scheme: dark`;
- темний фон option-елементів;
- окремі hover/focus/disabled-стани;
- мінімальну висоту для touch;
- збереження нативної поведінки, клавіатури та `FormData`.

Часові dropdown-и залишилися окремим уже наявним premium-компонентом.

## 3. Checkbox-и адмінки

Перевірено всі 14 checkbox-сценаріїв:

- документ перевірено;
- клієнту зателефонували;
- передоплату отримано;
- умови надіслано;
- залог отримано;
- корекція залогу;
- відмітка в сторіс;
- фінальний розрахунок;
- додаткові засоби;
- знижка 10%;
- лояльність;
- запам’ятати пристрій;
- інші службові підтвердження.

Тепер усі вони мають:

- єдину геометрію галочки;
- золотий checked-стан;
- однаковий hover/focus;
- checked-підсвічування всієї картки `.switch` або `.extra-check`;
- зрозумілий disabled-стан.

## 4. CI та перевірки

Додано автоматичні перевірки:

- усі 6 select покриті premium-стилем;
- усі 14 checkbox знаходяться у стандартизованих компонентах;
- calendar scroll lock присутній у JS;
- scrollbar gutter присутній у CSS;
- Playwright-сценарій перевіряє координату/ширину правого summary до і під час календаря;
- Playwright перевіряє стилі способу видачі, типу документа та checked-стан документа.

Playwright переведено на віртуальний static origin `https://vacleaner.test`, щоб GitHub Actions не залежав від локального порту.
