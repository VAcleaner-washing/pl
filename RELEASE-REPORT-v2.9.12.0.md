# VAcleaner v2.9.12.0 — Return Flow P0

## Виправлено

- Мобільна модалка «Закриття оренди» тепер займає реальну висоту екрана, має один внутрішній скрол і видимий футер без перекриття підсумку.
- Залог винесений на початок модалки окремим блоком; чітко відділений від оплати оренди.
- При закритті можна підтвердити, що залог отримано при видачі, та окремо — що його повернуто клієнту. Це також ремонтує старі бронювання, де відмітка не збереглася.
- Поле «Отримано при видачі» перейменовано на «Оплата оренди, отримана при видачі», щоб його не плутали із залогом.
- Поле кількості пакетиків більше не перетворює 0 + 1 на 10: при фокусі нуль очищається, введення санітизується як ціле число.
- Браузерні стрілки числових полів прибрані.

## База даних

- Для старих виданих бронювань відновлено стан отриманого залогу.
- Для вже закритих старих бронювань зафіксовано повернення залогу.
- Перевірка після міграції: 0 виданих бронювань без стану залогу; 0 завершених бронювань без стану повернення.

## Наступний план

- v2.9.13: P1 — SEO сторінки бронювання, ізоляція admin PWA, нормалізація фінансових назв.
- v3.0: P2 — рефакторинг даних клієнтів, аналітики, відгуків і остаточне прибирання технічного боргу.
