- Резервні часові слоти на фронтенді, в адмінці та сповіщеннях узгоджено з центральними 08:00–10:00 і 17:30–20:00.

## Що лишається керованим з адмінки

- доставка по Полтаві;
- часові слоти;
- залогові платежі;
- каталог, ціни та розрахунки бронювання.

Статичні маркетингові тексти більше не підміняються JavaScript після першого показу сторінки. JavaScript і Supabase продовжують завантажувати та застосовувати лише актуальні операційні налаштування.

## Захист від повторення проблеми

До GitHub Actions додано окремі перевірки цілісності текстів, назв комплектів, доставки, SEO та серверного пакета. Публікація зупиниться, якщо повернеться старе формулювання або розійдуться початковий HTML і JavaScript.
