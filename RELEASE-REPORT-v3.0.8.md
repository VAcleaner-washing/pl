# VAcleaner v3.0.8 — TRUSTED DEVICE SESSION

Статус: release candidate. Реліз створено поверх v3.0.7. Supabase production у цьому релізі не змінювався; активна `vacleaner-admin-bookings-v3` v10 залишається сумісною.

## Причина релізу

У v3.0.7 адмінська сесія зберігалася тільки в `sessionStorage`, через що після повного закриття PWA менеджеру доводилося входити повторно. Для щоденної роботи це надто жорсткий UX.

## Що змінено

- Додано опцію `Запам’ятати цей пристрій`, увімкнену за замовчуванням.
- При увімкненій опції сесія зберігається між закриттями PWA.
- Access/refresh token автоматично оновлюються через Supabase refresh flow.
- Сесія завершується після ручного виходу, відкликання токена Supabase або 30 днів без активності.
- При вимкненій опції сесія залишається тимчасовою та зберігається тільки до закриття браузерної сесії.
- Наявна сесія v3.0.7 автоматично переноситься в режим довіреного пристрою, якщо користувач не вимикав запам’ятовування.
- CSP, санітизація даних і серверний фінансовий розрахунок v3.0.7 не змінювалися.

## Що не виконувалося

- Supabase Edge Functions у v3.0.8 не деплоїлися, бо backend-логіка не змінювалася.
- GitHub Pages v3.0.8 не деплоївся з робочого середовища.
- Реальний вхід на домені після GitHub deployment ще не перевірено.
- Повний Deno type-check усіх Edge Functions не виконувався.
- Реальні Playwright-тести не додані до GitHub Actions.
