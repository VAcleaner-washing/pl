# VAcleaner v4.1.33 — NAVIGATION + TYPOGRAPHY UX

## Зміни
- Адреса доставки стала клікабельною в картці бронювання, «Найближчих» і деталях бронювання.
- iPhone/iPad відкривають Apple Maps з адресою як точкою призначення; Android/desktop — Google Maps directions. Стартова точка береться з поточного місця користувача навігатором.
- У редагуванні бронювання під полем адреси з’являється «Прокласти маршрут ↗», коли вибрана доставка й адреса не порожня; посилання оновлюється під час введення.
- Проведено типографічний UX-pass по всій адмінці: зменшено надмірну жирність заголовків, статусів, карток, модалок, клієнтів, аналітики та Campaigns, при цьому ключові суми/KPI лишилися сильнішими.
- «Фінальний розрахунок / Після повернення» більше не виглядає як дві важкі кнопки-тексти: label 520, значення 620, загальний ряд 500.
- Liquid Glass overrides також узгоджені з новою легшою ієрархією.

## Не змінювалось
- Supabase schema / Edge Functions.
- RETURN bonus та discount calculation.
- Booking pricing, deposit, status workflow.
- Public site logic.
