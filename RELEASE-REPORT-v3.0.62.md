# VAcleaner v3.0.62 — PUBLIC PACKAGE CARD DESKTOP ALIGN

## Що змінено
- На public-сторінці `/komplekty/` вирівняно вертикальний ритм desktop-карток у сітці комплектів.
- Для package cards додано спільні вертикальні зони: title, items, purpose, feature list, price та tariff copy.
- HOME RESET featured card зберігає окремий gift-badge layout без накладання на CTA.
- Оновлено cache-busting assets до `v=3062`.
- Оновлено static build guard під новий desktop alignment contract.

## Результат
- Ціни, тарифний рядок і CTA у desktop-картках `/komplekty/` тепер стоять рівніше в межах одного ряду.
- Візуально прибрано ефект, коли одна картка «провисає» через довший заголовок або опис.
