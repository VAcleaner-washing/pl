# VAcleaner v4.1.52 — manual address fallback

- Нерозпізнана адреса більше не показує лише «за погодженням».
- У полі, картці доставки, правому підсумку й мобільному підсумку видно: Полтава — 250 грн, передмістя — 350 грн.
- Менеджер підтверджує, який тариф застосовується, до передоплати.
- Для знайдених адрес збережено автоматичний розрахунок маршруту; для адрес поза стандартною зоною збережено окреме погодження.
- Початковий HTML і гідратований JavaScript використовують однакову нейтральну назву «Доставка».
