# VAcleaner v4.1.32 — RETURN DETACH + UX HIERARCHY

- Виправлено реальну причину, через яку RETURN після «Прибрати бонус» знову з’являвся: старий DB trigger захищав promo навіть під час явного detach.
- Explicit detach тепер має транзакційний service-role bypass; звичайні редагування й надалі не можуть випадково стерти кращий promo.
- Після attach/detach картка бронювання оновлюється одразу, без перезавантаження сторінки.
- Модалка редагування стала компактнішою: прибрано зайві пояснення, RETURN та ручна знижка займають менше висоти.
- Типографіка в бронюваннях спокійніша: жирність лишилась для суми/ключових акцентів, а не для кожного підпису.
- Додано CI regression test v4.1.32.
