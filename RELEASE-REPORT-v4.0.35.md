# VAcleaner v4.0.35 — Smart Guide Logic & Conversion

Дата: 12.08.2026

## Що виправлено

- прибрано неправдивий прогрес `Крок 1 з 1`; на старті квіз показує зрозумілий стан без вигаданого загального числа кроків;
- при видаленні зони очищаються всі залежні відповіді та засоби цієї зони;
- додано вибір `Шерсть, волосся або багато пилу`, який реально вмикає рекомендації Puzzi + Jimmy або `Генеральне`;
- для вікон об’єднано дубльовані варіанти рам і стиків;
- сценарії з рамами/стиками завжди отримують комплект зі SC 2;
- у результаті базова й знижкова ціна показані разом, а розрахунок −5% збігається із серверним округленням;
- окремий великий блок бонусу прибраний;
- сума та кнопка бронювання винесені в постійно видиму нижню панель результату;
- збережено вибір додаткових засобів без стрибка внутрішнього скролу;
- додано точний alias `Puzzi + робот для вікон` для передавання результату в бронювання.
