# VAcleaner v4.1.41 — FULFILLMENT UX + CI STABILITY

- У редагуванні/створенні бронювання «Самовивіз» більше не показує адресу доставки, під’їзд, address-helper або OpenStreetMap.
- «Доставка» одразу повертає блок адреси та робить адресу обов’язковою.
- При самовивозі приховане поле адреси disabled, тому стара адреса випадково не відправляється як доставка.
- Поле «Спосіб видачі» має max-content height і більше не розтягується висотою address-helper.
- Final desktop QA тепер реально перемикає Delivery → Pickup → Delivery і перевіряє видимість/геометрію.
- Виправлено flaky CI: тест картки клієнта клікає по імені клієнта, а не по центру рядка, де міг опинитися tel-посилання.
