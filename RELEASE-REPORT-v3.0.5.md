# VAcleaner v3.0.5 — зрозумілий текст залогу

## Виправлено
- У підсумку бронювання: **«Поворотний залог»** замість технічного «Залог при видачі».
- Підпис: **«сплачується під час отримання техніки»**.
- Прибрано фразу про те, що менеджер фіксує іншу фактичну суму.
- У блоці **«Що потрібно для оформлення»** додано просте пояснення фінального взаєморозрахунку:

> Після повернення техніки із передоплати та залогу вираховується вартість оренди, доставки, додаткових засобів і використаної хімії. Залишок повертається клієнту або клієнт доплачує різницю.

- Додано видалення дубльованих рядків залогу в підсумку, якщо старі runtime-скрипти встигли створити більше одного елемента.
