# VAcleaner v4.0.41 — Package Cache Bust

Дата: 12.08.2026

## Причина випуску

У v4.0.40 назви комплектів було оновлено в HTML і JavaScript, але змінені Next.js-файли зберегли старі URL. Chrome міг використати кешовану копію та після гідрації повернути старі назви.

## Що виправлено

- Файл бронювання отримав нове унікальне ім’я чанка.
- Аналогічно оновлено змінені чанки сторінки комплектів і адмінки.
- Усі HTML/RSC-посилання та тести переведено на нові URL.
- Додано build-контракт, який не дозволить знову випустити посилання на старі кешовані чанки.

## Результат

Оновлені назви завантажуються для всіх користувачів без ручного очищення кешу або Ctrl+F5.
