# VAcleaner v4.1.31 — QUIZ DISCOUNT CLARITY + CI FIX

## Що змінено

- У картці бронювання статус **«Видана»** став легшим за вагою та читабельнішим.
- Рядок додаткових позицій на кшталт **«Насадки Преміум»** більше не виглядає надто жирним.
- Бронювання, що прийшло через **«Підбір за 30 сек»**, тепер має окрему позначку в картці.
- Для знижки з QUIZ-кампанії показується причина **«Знижка за підбір»**, а не абстрактне «промо».
- У детальному фінансовому блоці при наявності знижки окремо видно: оренда до знижки → причина/сума знижки → оренда після знижки.
- Виправлено CI-регресійний тест v4.1.28, який очікував стару структуру `pendingPromo` в customer lookup після того, як pending-бонус було винесено в Campaign API.
- У GitHub Actions додано перевірки v4.1.29, v4.1.30 та новий тест v4.1.31.
- Оновлено PWA visual QA під активаційний funnel v4.1.30 (`SMS → активовано → використано`), щоб деплой не падав далі на застарілому очікуванні.

## Не змінювалось

- Логіка бронювання та тарифів.
- RETURN 21-day activation/redeem logic.
- Supabase schema та міграції.
- PWA auth/session logic.
