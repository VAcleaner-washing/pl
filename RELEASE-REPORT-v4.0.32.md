# VAcleaner v4.0.32 — продаж додаткових засобів без пломб

## Що оновлено

- Публічний каталог переведено з Carp-Deta на дві нові позиції:
  - VA SPOT FIX · 50 мл · 100 грн;
  - VA STAIN OX · 30 мл · 100 грн.
- Додано картки засобів, призначення, інструкції та застереження.
- У Smart Guide замінено питання про плями та запахи, додано мультивибір і окремі рекомендації для звичайних та старих кольорових плям.
- Результат квізу показує конкретний комплект, додаткові засоби, орієнтовну суму й передає вибір у бронювання.
- У формі бронювання доступні обидва плямовивідники; старий Carp-Deta приховано.
- В адмінці додано обидві позиції, описи й ціни.
- Якщо засіб додано до бронювання, його ціна одразу входить у замовлення та фінальний розрахунок.
- Старі бронювання з Carp-Deta зберігаються як історичні записи.

## Backend

- Каталог Supabase синхронізовано.
- Оновлено Edge Functions `vacleaner-settings`, `vacleaner-booking-v5` і `vacleaner-admin-bookings-v3`.
- Серверний розрахунок враховує кожну додану позицію одразу, як звичайний продаж.

## Перевірки

- Build check: 311 файлів.
- Stabilization contract: 170 перевірок.
- Finance tests: стандартні сценарії та сумісність зі старими записами `on_open`.
- Backend inventory: пройдено.
- Playwright browser smoke не запускався в робочому середовищі через відсутній пакет `playwright`.
