# VAcleaner — CSS consolidation & responsive QA (v2.9.6.0)

Основа: `VAcleaner-v2.9.5.2-MOBILE-MORE-BUTTON-FIX.zip`.

## Що зроблено

`assets/admin-v250.css` перебудовано в канонічну структуру: спочатку базові правила, далі згруповані брейкпоінти, наприкінці — один блок гарантій взаємодії. Історичні version-patch блоки більше не нашаровуються один на один.

- `!important`: **759 → 1**. Єдиний залишений випадок — службовий `.hidden { display:none !important; }`.
- Дублікати однакового селектора в одному CSS-контексті: **248 → 3**.
- CSS-правила: **1263 → 1022**.
- Стилі відформатовані: один селектор — один читабельний рядок.

## Додаткові виправлення, знайдені під час реального рендера

- Кнопка **«Ще»** і меню Клієнти / Аналітика / Хімія / Налаштування коректно працюють не лише на телефоні, а й на планшетах 768–834 px.
- Поле дати у формі бронювання більше не стискається до однієї цифри: `date-control` має окремі колонки для дати та кнопки календаря.
- Усі текстові поля, select і textarea в модалках мають `font-size:16px` — без iOS auto-zoom.
- Кнопки закриття, часові чіпи, швидкі суми, телефонні посилання та основні дії мають ефективну зону натискання від 44 px.
- Редактор каталогу на 320 px переходить в одну колонку, поля цін не стискаються.
- Календар на 901–1100 px переходить у 2 колонки й не виходить за viewport.
- Список клієнтів на 761–1100 px перебудовується у компактні рядки без обрізання останньої колонки.
- Прибрано подвійний виклик реєстрації Service Worker; кеш піднято до `v2960`.

Базова матриця: **8 розділів × 9 ширин = 72 рендери**:
`320, 360, 390, 414, 768, 834, 1024, 1280, 1440 px`.

Окремо: **96 інтерактивних рендерів** — нове бронювання, деталь, опрацювання заявки, фінанси, редагування, видача, повернення, бронювання зі слота, редактори цін і меню «Ще».

Фінальний результат автоматичних детекторів:

- горизонтальний scroll/visible overflow: **0**;
- поля з font-size <16 px: **0**;
- ефективні tap-targets <44 px: **0**;
- console error/warning: **0**.
