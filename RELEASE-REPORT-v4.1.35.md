# VAcleaner v4.1.35 — POLTAVA + SUBURBS ADDRESS UX

- Пошук адрес розширено з Полтави на Полтаву та найближче передмістя у радіусі до 30 км від центру.
- Підказки зберігають реальний населений пункт: Полтава, Розсошенці, Щербані та інші адреси, які повертає карта в межах сервісної зони.
- Навігатор більше не підставляє «Полтава» перед уже нормалізованою адресою передмістя.
- Під адресою доставки залишається окреме поле «Під’їзд / квартира / поверх» для квартири, під’їзду, поверху, домофона чи короткої примітки кур’єру.
- Загальний «Коментар» бронювання не прибраний і не змішаний з логістикою: він залишається для того, що клієнт планує чистити, побажань та підбору хімії.
- Однакова логіка діє на публічному бронюванні та при створенні/редагуванні бронювання в адмінці.
- Supabase Edge Function `vacleaner-address-v1` оновлена у production до версії 3.
