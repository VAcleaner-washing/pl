VAcleaner · production 301 redirects

GitHub Pages не виконує серверні 301. Для vacleaner.pp.ua створіть у Cloudflare
Redirect Rules → Single Redirect такі постійні перенаправлення (301):

/karcher-puzzi.html       → /rishennia/textile
/jimmy-jv35.html          → /rishennia/mattress
/karcher-sc2.html         → /rishennia/steam
/abir-wd8.html            → /rishennia/windows
/rishennia/index.html     → /rishennia
/komplekty/index.html     → /komplekty
/yak-tse-pratsiuie/index.html → /yak-tse-pratsiuie
/vidhuky/index.html       → /vidhuky
/faq/index.html           → /faq
/kontakty/index.html      → /kontakty
/umovy/index.html         → /umovy

У збірці вже є безпечні fallback-сторінки для старих адрес, але саме Cloudflare
правило забезпечує HTTP 301 до завантаження HTML.
