# VAcleaner v3.0.63 — HOME PACKAGE CARD ALIGN (BASE 3.0.61)

## База
Цей реліз створено безпосередньо з прийнятої збірки v3.0.61. Код від відхиленої v3.0.62 не використовувався.

## Зміна
- Виправлено тільки секцію комплектів на головній сторінці `/#top`.
- На desktop (`>=901px`) три картки `.v21-package-grid` мають спільну дворядкову зону заголовка.
- Це синхронізує вертикальні позиції опису, ціни, підпису/економії та нижнього CTA.
- `/komplekty/`, адмінка, PWA shell, Supabase і бізнес-логіка не змінювались, окрім release/cache version identifiers.

## Причина
Середня картка `Puzzi + SC 2 + Jimmy` мала дворядковий заголовок, тоді як сусідні — однорядковий. Через це весь наступний контент середньої картки зсувався вниз.
