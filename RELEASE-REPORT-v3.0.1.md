# VAcleaner v3.0.1 — P3 Architecture + correct settlement

Базова збірка: **v3.0.0 P3 Architecture**.

## Що збережено з v3.0.0

- єдиний `config/vacleaner.json` для каталогу, слотів, залогів і назв;
- генерація `vacleaner-core.js` та Supabase `config.ts`;
- чистий GitHub Pages build без службових файлів;
- ізольована PWA адмінки в `/admin/`;
- аудит змін бронювань та production security hardening;
- консолідований CSS без повернення до старої системи патчів.

## Що виправлено у v3.0.1

- правильна фінансова модель: `передоплата + фактичний залог − усі витрати`;
- при видачі менеджер фіксує фактичний залог, який може відрізнятися від базового;
- при поверненні система показує суму до повернення клієнту або доплату;
- хімія рахується за фактично використаними пакетиками, перші два безкоштовні за сторіс;
- поле пакетиків порожнє при нулі, введення `1` не перетворюється на `10`;
- у новому бронюванні додані тип документа, номер і відмітка перевірки;
- паспортні дані повторного клієнта підтягуються за телефоном;
- публічний підсумок пояснює 200 грн бронювання, базовий залог і фінальний взаєморозрахунок;
- повідомлення менеджера в Telegram пояснює ту саму модель без суперечностей.

## Backend

Файл `supabase/functions/vacleaner-admin-bookings-v3/index.ts` зберігає P3-конфігураційну архітектуру та записує фінансовий snapshot у `extras.settlement`.
